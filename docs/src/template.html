cc-changelog-tracker

架構圖與狀態流程圖

定時偵測 Claude Code CHANGELOG 的新版本. Claude 負責分類和摘要, Gemini 負責翻譯, 最後送到 Discord.

架構圖 狀態流程圖

架構圖

模組之間的相依關係, 以及每個模組使用的外部服務.

  • tracker.ts 負責整個流程. 其他模組透過 TrackerDeps 注入, 所以測試時可以換成假的實作.
  • classifier.ts 透過 Agent SDK 啟動 Claude Code CLI 子程序. 這個子程序沒有任何工具, 也不讀取使用者設定.
  • 只有 state.ts 會寫入檔案. 寫入時先寫暫存檔再 rename, 避免留下不完整的檔案.

狀態流程圖

    
一次檢查 (checkOnce) 的狀態變化. 一次檢查結束後才開始計時, 所以兩次檢查不會同時執行.

    

    
    
      
  • 每送出一個版本, 就保存一次 lastVersion. 這時仍保留舊的 ETag.
    • 
      
  • 所有新版本都送出後, 才保存新的 ETag. 如果中途失敗, 下次檢查會重新下載, 並從失敗的版本繼續.
    • 
      
  • 第一次執行只記錄目前的最新版本, 不送出歷史版本的通知.
